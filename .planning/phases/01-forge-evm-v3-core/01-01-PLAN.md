## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub release → local dependency gitlink | External Solidity source enters the repository and becomes the canonical arithmetic oracle. |
| Foundry build → repository worktree | Build commands generate cache, bytecode, and broadcast artifacts that must not become source inputs. |
| Local harness → upstream TickMath | The wrapper must preserve upstream arithmetic and error semantics rather than substitute local logic. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-1-01 | Tampering | `evm/lib/v4-core`, `.gitmodules`, `evm/foundry.lock` | high | mitigate | Install the exact official tag, require SHA `e50237c43811bd9b526eff40f26772152a42daba`, and track the gitlink plus generated lock. |
| T-1-02 | Tampering | `evm/cache`, `evm/out`, `evm/broadcast` | medium | mitigate | Add narrow ignore rules and verify no files under generated artifact roots are tracked. |
| T-1-03 | Elevation of privilege | `evm/foundry.toml` execution capabilities | medium | mitigate | Keep the scaffold on the default non-FFI build profile and omit relay, filesystem permission, and cheat-surface configuration under D-06. |
| T-1-04 | Repudiation | Dependency provenance documentation | low | accept | Local-only scaffold has no transaction audit boundary; README, lock, gitlink, and commit history provide adequate provenance at ASVS L1. |
</threat_model>
